# 關鍵流程

## 1. 首次使用與建檔

**參與者**：使用者、Codex代理
**前置條件**：當前任務中不存在完整使用者檔案
**成功結果**：形成最小必要檔案，並確定眼前問題和情緒強度

1. 使用者顯式調用 Skill 或提出符合描述的戀愛問題。
2. 代理先處理緊急情緒或必須馬上回覆的事項。
3. 代理收集本人MBTI和主觀綜合評分。
4. 代理為一個或多個目標對象收集代號、MBTI、主觀評分和關係階段。
5. 代理瞭解關鍵事件、聯繫頻率、雙方投入、主要障礙、目標和情緒強度。
6. 代理復述檔案，標記未知與矛盾，不填造缺失事實。
7. 需要跨任務復用且尚未選擇時，用一句話詢問本地精簡記憶同意；同意後自動更新並提示撤銷，拒絕後不阻塞服務。

**隱私邊界**：只需使用代號；不需要真實姓名、地址、帳號、身份證件或私密照片。使用者明確提供的姓名、暱稱或代號可在同意長期記憶後進入本地對象檔案。

## 2. 常規關係分析

**前置條件**：擁有足夠的使用者敘述或檔案
**成功結果**：使用者獲得可解釋、可執行且保留選擇權的建議

1. 用簡短語言確認情緒與內在衝突。
2. 把敘述拆分為已知事實、合理推測和關鍵未知。
3. 根據場景讀取必要參考文件。
4. 比較互惠、可靠、吸引、價值觀、現實可行性、風險和機會成本。
5. 給出明確首選建議和關鍵理由。
6. 必要時提供穩健、策略或強勢版本。
7. 收束為一件小事、觀察窗口、停止條件和反饋訊號。

**拒絕路徑**：若使用者要求實施違法、強迫、跟蹤、詐騙或繞過同意的行為，代理拒絕該操作部分，解釋風險並提供低風險替代。

## 3. 聊天材料分析與即時回覆

1. 判斷素材來自聊天截圖、匯出文本、複製對話、使用者轉述、通話、線下互動或混合來源。
2. 長記錄先建立並顯示固定的使用者／對象說話人映射；ChatLab或匯出優先使用發送者ID，截圖請使用者確認側邊或暱稱，不能按左右、語氣或性別猜。
3. 只把可確認的原文、發送者、順序、間隔和行為寫入事實；把含義解釋放入推測。
4. 承接使用者明確表達的當下情緒，再判斷本輪主要目標是承接、調侃、推進、邀約、澄清還是收線。
5. 使用者只要一句回覆時，第一屏先給一條符合使用者口吻、可直接發送的首選成品。
6. 按對方積極、含糊或拒絕反應給出後續分支；需要練習時每輪只模擬一條回覆並等待使用者接話。

## 4. ChatLab匯入與分析

1. 已有ChatLab會話時先讀取manifest和會話列表，消除會話、成員和“誰是使用者”的歧義，並在分析前顯示固定映射。
2. 使用者提供匯出文件時確認唯一絕對路徑，先執行只讀dry-run；只報告格式和數量，不展示正文。
3. 從時間、對象和問題都最窄的專用查詢開始，只在證據不足時補上下文或統計。
4. 回答標明會話和時間範圍，引用訊息編號，區分事實、解釋和未知。
5. 使用者要求直接匯出通訊軟體資料時說明能力邊界，不調用解密或權限繞過工具。
6. 原始聊天不寫入長期記憶；只有已同意使用者的關鍵事件摘要和證據編號可進入事件層。

## 5. 主動約會與第一次見面

1. 沒有明確拒絕或不適時，給出至少一個主動聯繫、具體邀約或真實表達動作。
2. 第一次見面建議保持簡潔，覆蓋可交談的地點、共同體驗、具體欣賞和結束時的真實反饋。
3. 根據雙方對恐怖、密閉、運動、噪音和人群的偏好選擇活動，不把“吊橋效應”寫成保證吸引的公式。
4. 肢體互動結合關係與現場適當創造自然、低強度、可退出的機會，並根據對方反應調整。
5. 根據明確拒絕、不適或現實危險停止；拒絕只針對具體時間或方式時，先澄清而不自動推斷為整段關係的拒絕。

## 6. 多目標對象比較

1. 為每個對象保留獨立代號與事件記錄。
2. 不用一個對象的MBTI、行為或話術填補另一個對象的資訊。
3. 分別評估互惠、可靠、相處體驗、現實可得性和長期風險。
4. 比較“高評分但不可得”和“評分較低但互惠穩定”的真實差異。
5. 保留“暫不選擇任何人”作為合法選項。

## 7. 長期記憶更新與控制

1. 每輪只提取會改變未來建議的少量變化；重復內容更新原欄位，不追加副本。
2. 使用者穩定檔案只接受本人明確陳述；ChatLab、其他工具和模型推斷只能進入事件或假設。
3. 成功更新後顯示一句摘要與撤銷方式；失敗時說明未持久化。
4. 使用者可隨時查看、暫停、恢復、撤銷、忘記對象、撤回同意或清空全部。
5. 達到條數上限時合併或刪除低價值事件，不擴容；刪除對象時同時清除可能恢復該對象的撤銷歷史。

## 8. 高情緒強度

1. 先縮小時間範圍，避免連發、報復、突然刪除或其他不可逆動作。
2. 建議暫存訊息、離開刺激源或聯繫可信的人陪伴。
3. 在情緒下降後再進入事實分析和策略選擇。
4. 若存在立即自傷或傷人危險，轉入緊急支持，不繼續只給戀愛話術。

## 9. 暴力、控制與危機

1. 識別暴力、性脅迫、跟蹤、財務控制、隱私威脅或詐騙訊號。
2. 讀取法律安全與危機轉介文件。
3. 優先人身安全、可信支持、證據保存和當地專業服務。
4. 不建議使用者在不安全環境中單獨攤牌或以伴侶咨詢替代安全計畫。
5. Skill只提供一般資訊；現實緊急情況由當地緊急服務和合格專業人員處理。
