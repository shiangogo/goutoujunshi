很多戀愛建議只有兩個答案：“勇敢去追”或“趕緊分手”。狗頭軍師不會只憑一句話替你下結論：它先接住情緒，再把事實、推測和未知拆開；既看心動，也看現實條件、互惠、風險、機會成本和長期選擇權，最後給出可以真正執行的下一步。

它不只是一個話術庫。它能讀取聊天截圖、匯出文本和使用者轉述，區分素材來源與事實邊界；也能把分析落到一句可發送的話、一次具體邀約、第一次見面安排或一段可復盤的對話演練。它是一套覆蓋戀愛全週期、面向多元關係、能夠解釋建議理由的跨平台 AI 軍師 Skill（原生支援 Antigravity CLI、Claude Code 與 OpenAI Codex）。

## 它能幫你解決什麼

| 你遇到的問題 | 狗頭軍師會怎麼幫 |
| --- | --- |
| 不知道這句話怎麼回 | 先給一條能直接發送的話，再補時機和後續分支 |
| 想追求、復聯、邀約或推進關係 | 給具體行動方案，按照對方回饋繼續調整 |
| 看不懂對方，或在多人之間猶豫 | 結合行為、MBTI、主觀評分和現實條件給明確判斷 |
| 聊天太長、截圖太多 | 鎖定雙方說話人，區分事實、推測和未知；也可分析 ChatLab 已有資料 |
| **希望以後不用重複交代背景** | **長期記憶**：首次明確同意後，跨任務記住雙方檔案和關鍵進展；自動更新、按需召回，隨時可以查看、暫停、撤銷或清空 |
| 遇到冷淡、衝突、投入失衡、分手或婚姻選擇 | 接住情緒，分析利弊，給下一步、觀察窗口和停止條件 |

## 不預設你應該愛誰

狗頭軍師支持異性戀、男同性戀、女同性戀、雙性戀、泛性戀、無性戀等不同性取向，也尊重跨性別、非二元性別及其他性別身份。它同樣可以討論單身約會、長期伴侶、婚姻、異地、再婚、跨文化關係，以及建立在知情同意基礎上的非單偶關係。

系統不假設固定的性別角色：男女和多元性別使用者都可以主動，任何人也都可以選擇高主動模式。對於臺灣常見的男女性約會語境，系統可能在沒有明確拒絕或不適時建議男性把主動度提高一級，但這只是可被個人偏好和現實回饋覆蓋的文化校準，不是“男性必須追、女性只能等”的定律。判斷依據始終是具體的人、具體行為、雙方意願和現實條件。

## 安裝與使用指南（支援 Antigravity / Claude Code / Codex）

本專案遵循 Progressive Disclosure 漸進式載入規範，原生相容 **Antigravity CLI (`agy`)**、**Claude CLI (Claude Code)** 與 **OpenAI Codex**，支援全域安裝與專案工作區安裝。

### 1. Antigravity CLI (AGY) / Antigravity IDE

- **方式 A：在 Antigravity 對話框中直接安裝（推薦）**：
  ```text
  請將公開倉庫 https://github.com/shiangogo/goutoujunshi 下載並安裝到我的 Antigravity Skills 目錄（~/.gemini/config/skills/goutoujunshi）。
  ```
- **方式 B：終端機安裝**：
  ```bash
  # 全域安裝（推薦，本機所有工作區皆可呼叫）
  mkdir -p ~/.gemini/config/skills
  git clone https://github.com/shiangogo/goutoujunshi.git ~/.gemini/config/skills/goutoujunshi

  # 或專案工作區安裝（僅特定專案生效）
  mkdir -p .agents/skills
  git clone https://github.com/shiangogo/goutoujunshi.git .agents/skills/goutoujunshi
  ```
- **啟動方式**：Antigravity 會依對話語境自動辨識載入，亦可直接開口呼叫：
  ```text
  請使用狗頭軍師幫我梳理情緒、分析當前關係，並給出下一步建議。
  ```

### 驗證 Skill 完整性（所有平台通用）

```bash
python3 scripts/validate_skill.py
```

首次使用時，它會引導你建立精簡關係檔案：

```text
你：MBTI / 綜合評分0–100 / 主要優勢和短板
對象A：代號 / MBTI / 綜合評分0–100 / 當前關係
對象B（如有）：同上
經過：認識方式、發展時間、關鍵事件、聯繫和投入情況
目標：推進、確認、修復、比較選擇，還是退出
情緒：目前最難受的點、強度0–10，以及是否有必須馬上回覆的訊息
```

不知道的欄位可以留空，也可以直接講故事、貼上 LINE/IG 對話或截圖。Skill 會從敘述中整理檔案，並只追問真正會改變建議的資訊。需要跨任務復用時，Skill 會單獨詢問一次是否允許在本機保存精簡檔案（透過 `scripts/memory_store.py` 儲存於本機 SQLite）；拒絕不影響正常使用。

### 分析已匯出的聊天檔案

ChatLab 是可選依賴。安裝並準備好使用者自己取得的聊天匯出檔案後，可以直接說：

```text
請使用狗頭軍師透過 ChatLab 分析我和對象A最近三個月的聊天。
```

狗頭軍師會先預覽匯入計畫，再限定會話、對象和時間範圍查詢。它不會直接讀取、解密或匯出通訊軟體資料庫；沒有 ChatLab 時仍可直接貼上文字或上傳截圖分析。

## 一個典型回答如何產生

```text
使用者敘述
  → 情緒落地
  → 建立本人及目標對象檔案
  → 分離事實／推測／未知
  → 檢索當前情境所需知識
  → 比較互惠、現實、風險與機會成本
  → 給出明確首選建議和理由
  → 生成行動、話術、觀察窗口與停止條件
```

長期記憶和 ChatLab 只在使用者同意或提供相應資料時按需使用，不改變這條核心分析流程。

## 設計原則

1. **先接住人，再解決事。** 情緒沒有被看見時，最正確的建議也可能無法執行。
2. **行為比標籤可靠。** 不憑 MBTI、性別或一次聊天紀錄替目標對象讀心。
3. **互惠比追到更重要。** 得到某一個人不是唯一勝利；減少內耗、保留尊嚴與未來選擇權同樣是成功。
4. **策略必須說明代價。** 可以討論撒嬌、推拉、節奏和表達包裝，但同時交代適用條件與長期成本。
5. **同意和退出權不可繞過。** 明確拒絕不是需要破解的障礙。
6. **危險情境先保安全。** 暴力、脅迫、跟蹤、詐騙和自傷風險不能用普通戀愛話術處理。
