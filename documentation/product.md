# 產品定位

## 產品主張

狗頭軍師不是替使用者做主的“感情裁判”，而是一個同時處理情緒、資訊和行動的戀愛決策助手。它幫助使用者從混亂敘述、聊天截圖或匯出文本中建立關係檔案，識別事實和讀心之間的距離，比較繼續、主動推進、溝通、觀察、降級投入或退出的真實代價，並把建議轉化為可發送的話和可執行的下一步。

## 核心使用者與價值表達

| 使用者 | 典型困境 | 價值表達 |
| --- | --- | --- |
| 曖昧與約會中的使用者 | 看不懂訊號，反復猜測，不知道怎樣推進 | 把零散互動整理成互惠證據，並給出邀約、觀察窗口和停止條件 |
| 提供聊天紀錄的使用者 | 截圖、匯出文本、轉述和線下互動混在一起，擔心被過度腦補 | 區分素材來源、可見原文、事實、推測和未知，再按上下文生成可發送回覆 |
| 衝突中的伴侶 | 情緒很強，想連發、質問、冷戰或分手 | 先降低衝動成本，再提供能表達感受、邊界和具體請求的對話方案 |
| 多人選擇中的使用者 | 心動、條件、穩定與現實可行性相互衝突 | 分開維護對象檔案，比較可靠、互惠、價值觀、現實和長期選擇權 |
| 分手或背叛後的使用者 | 想復合、報復、自責或無法停止關注 | 區分止痛衝動與關係可修復證據，設計恢復、驗證或體面退出路徑 |
| LGBTQ+與多元關係使用者 | 普通建議預設異性戀、性別分工或單一婚姻腳本 | 不預設性別角色，以知情同意、互惠、現實條件和個人目標為判斷基礎 |
| 內容創作者與關係教育者 | 需要結構化框架，而不是碎片化金句 | 提供跨心理、社會、法律、人文、哲學與性學的主題知識和使用邊界 |

## 差異化能力

1. **情緒與決策一體化**：不是分析完就結束，而是確認使用者在當下能否執行。
2. **多人檔案**：原生支持一個使用者對應多個目標對象，不把事件和判斷串線。
3. **行為證據優先**：MBTI只作為檔案線索和提問參考，並始終用真實行為校正，不直接生成性格或關係結論。
4. **聊天材料識別**：區分截圖、匯出文本、轉述、通話、線下互動和混合素材，不補寫材料外的情節。
5. **可選ChatLab證據檢索**：分析使用者已經匯入或明確提供的聊天匯出文件，保留訊息編號並限制查詢範圍；不直接匯出通訊軟體數據。
6. **同意後精簡記憶**：本機保存使用者、對象、關係快照和關鍵事件；自動更新可見、可撤銷、可暫停和可硬刪除，並設總量上限。
7. **即時話術與演練**：先給一條可發送的首選成品，再提供反饋分支或按需模擬對話。
8. **主動約會支持**：幫助使用者表達真實喜歡、準備第一次見面、設計共同體驗，並根據反饋調整自然接觸。
9. **策略分級**：既不把所有社交策略妖魔化，也不隱藏短期效果背後的長期代價。
10. **跨學科路由**：按當前場景讀取必要知識，不一次塞入整套資料。
11. **明確停止條件**：把“再看看”變成可觀察、可截止、可退出的行動計畫。

## 非目標

- 不診斷心理疾病，不替代心理治療或醫療服務。
- 不充當律師、警方、緊急救援或家暴風險評估機構。
- 不預測特定對象一定會愛上使用者。
- 不幫助繞過同意、拒絕、隱私或法律邊界。
- 不用MBTI、性別、性取向或星座決定關係命運。
- 不在未同意時保存跨任務檔案；長期記憶保持精簡有界，不把記憶同步到倉庫或外部服務。
- 不直接讀取、解密或匯出 LINE、微信、QQ 等通訊軟體資料庫。

## 產品成功訊號

當前倉庫沒有遙測。未來評估應使用匿名或合成案例，關注：

- 非緊急且當前沒有完整檔案時，是否使用緊湊問卷收集最小必要資訊；緊急時是否先處理眼前問題，未知是否允許留空。
- 回答是否準確區分事實、推測和未知。
- 聊天截圖、匯出文本、轉述和線下互動是否被正確識別且沒有跨媒介腦補。
- 是否給出明確建議、理由、下一步和停止條件。
- 使用者只要回覆話術時，第一屏是否有一條符合原文和使用者口吻的可發送成品。
- 沒有明確拒絕、不適或危險時，是否至少給一次主動聯繫、具體邀約或真實表達；退出、衝突或持續缺乏投入時是否避免強行推進。
- 是否避免把使用者引向更高風險或更少選擇權的行為。
- 不同性取向、性別身份和關係結構下，建議質量是否一致。
- 高風險場景是否正確切換到安全優先流程。
- 長期記憶是否經過首次同意、只寫高價值變化、每次提示且可撤銷，達到上限時不繼續膨脹。
- ChatLab是否只處理使用者已有匯出文件、限制查詢範圍、保留證據編號並拒絕直接匯出承諾。

## 路線圖

- 建立匿名合成案例評測集，覆蓋約會、衝突、多人選擇、分手和危機場景。
- 為引用資料加入更新時間、來源類型和復核狀態元數據。
- 為長期記憶增加可視化審閱與欄位級編輯介面；當前版本使用本地命令查看、撤銷和刪除。
- 擴展地區化法律與求助資訊，並將其與通用關係建議嚴格分離。
- 增加繁體中文和英文內容，同時保留本地文化與家庭語境。
