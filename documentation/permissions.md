# 權限邊界

## 運行角色

| 角色 | 能力 | 不能做什麼 |
| --- | --- | --- |
| 使用者 | 提供資訊、選擇是否採用建議、決定是否啟用宿主工具 | 不通過本 Skill 自動獲得他人帳號、位置或私密資料 |
| AI 代理 (AGY / Claude / Codex) | 讀取 Skill 與按需參考；使用者同意後調用本地記憶腳本；按使用者請求調用 ChatLab | 不自動發送訊息、不直接匯出通訊軟體資料、不繞過工具核准 |
| 倉庫維護者 | 修改公開文件、審查貢獻和發佈版本 | 無權訪問使用者在私人對話任務中的內容 |
| 貢獻者 | 通過Issue或PR提交公開內容 | 不應提交可識別的真實關係案例或未經授權的私密材料 |

## 資源與操作矩陣

| 資源 | 使用者 | AI 代理 | 維護者／貢獻者 |
| --- | --- | --- | --- |
| `SKILL.md`與參考資料 | 可讀取 | 可讀取 | 通過Git修改公開副本 |
| 當前任務對話 | 可提供和查看 | 僅按宿主上下文訪問 | 預設不可訪問 |
| 使用者本地文件 | 按宿主授權 | 僅在宿主提供工具且使用者授權時訪問 | 不可訪問 |
| 本地精簡記憶 | 可同意、查看、暫停、撤銷和刪除 | 僅按同意狀態和腳本門禁讀寫 | 預設不可訪問，絕不進入倉庫 |
| ChatLab本地資料 | 使用者負責取得匯出文件並決定匯入 | 只按使用者請求預覽匯入或只讀查詢 | 預設不可訪問 |
| 外部訊息或帳號 | 使用者自行操作 | 本 Skill 不要求寫權限 | 不可訪問 |
| GitHub倉庫 | 公開讀取 | 無運行時要求 | 按GitHub倉庫權限貢獻 |

## 資料與權限實作

倉庫本身沒有使用者資料庫、令牌、角色聲明或行級安全機制。`memory_store.py`只在使用者首次同意後於本地使用者資料目錄建立限量SQLite文件，並使用來源、條數和撤銷校驗；它不提供跨操作系統帳號隔離。ChatLab為可選外部本地工具，其安裝、文件訪問和資料安全仍由使用者與宿主權限控制。
