# 公開表達案例的倫理轉譯

## 來源定位

- **北瘋小同學**：公開內容以直播連麥、即興接話、詩詞化情話、幽默和臨場口才為主。大量網路材料是切片或二手語錄，不視為作者課程、心理學事實或可核驗名言庫。
- **鄙人李洋洋**：公開內容覆蓋主動表達、聊天破冰、曖昧推進、約會、關係維護和分手心態。屬於創作者經驗和娛樂化表達，不是關係科學研究。

只參考創作者本人公開發佈或能確認來源的內容；不收錄盜版課程、付費內容搬運、完整逐字稿或無法確認歸屬的“經典語錄”。

公開核對入口（2026-08-02復核）：[北瘋小同學公開資料](https://www.baike.com/wikiid/7431861350086213673)、[鄙人李洋洋B站作品檢索](https://search.bilibili.com/all?keyword=%E6%9D%8E%E6%B4%8B%E6%B4%8B)、[本人發佈的《戀愛掌握主動權》](https://www.bilibili.com/video/BV1dC4y1K7cm/)。北瘋內容若只能找到第三方切片，不歸納為本人穩定主張。

## 可以吸收的能力

1. **北瘋式表達**：從現場細節取材，用意象、反差、幽默和適度誇張提升情緒張力。
2. **李洋洋式行動感**：減少被動猜測，用輕鬆、直接、可承擔結果的方式表達興趣和推進關係。
3. **共同底層**：短句、具體、有人味，敢於表達但允許對方不接。

## 必須過濾的部分

- 不把“拿下、套路、讓人離不開”作為成功指標。
- 不把詩意、口才或高情緒強度誤當承諾、可靠或關係質量。
- 不捏造經歷、身份、財富、未來或稀缺性來製造吸引。
- 不把直播中的即時效果直接複製到嚴肅衝突、分手、安全或長期關係決策。
- 對方明確拒絕、僵住、回避或表示不適時立即降級，不用更強表達繼續施壓。

## 輸出方法

先確定真實目的，再選擇表達風格：

```text
真實意圖 → 一句具體事實或欣賞 → 輕微意象/幽默 → 可退出的邀請
```

示例骨架：

> 剛才你認真講那件事的時候挺吸引我的。週末要不要一起喝杯咖啡？不方便也沒關係。

需要“北瘋感”時只提高畫面感和語言張力；需要“李洋洋感”時只提高直接度和行動感。始終保留使用者本人口吻、對方選擇權、適用條件和失敗後的體面收線。
